Chrome · HOW TO

Reopen a past browsing session

A quick, practical reference you can use right away.

START HERE · FAST PATH
Chrome → History
⎙ Print

How to do it

Step 1

Open Chrome's History menu

Step 2

Choose a recent closed window if one appears

Step 3

Reopen only the pages you still need

EXAMPLE / WHEN THIS HELPS

Recover a closed research window.

Good to know

BONUS — private browsing windows cannot be recovered this way.
