Outlook · HOW TO

Schedule an email for later

A quick, practical reference you can use right away.

START HERE · FAST PATH
New Message → Send dropdown → Schedule Send
⎙ Print

How to do it

Step 1

Compose the message and add a recipient

Step 2

Open the arrow beside Send and select Schedule Send

Step 3

Pick a date and time; confirm and verify it appears in Drafts

EXAMPLE / WHEN THIS HELPS

Schedule a harmless email to yourself.

Good to know

Requires a supported Microsoft 365 or Exchange account; options may differ in web Outlook.
