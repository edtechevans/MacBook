MacBook · HOW TO

Choose what opens at login

A quick, practical reference you can use right away.

START HERE · FAST PATH
System Settings → General → Login Items & Extensions
⎙ Print
Original English guide

How to do it

Step 1

Open Login Items & Extensions

Step 2

Review Open at Login; select an unnecessary app and click minus

Step 3

Add only essential apps using the plus control if permitted

EXAMPLE / WHEN THIS HELPS

Remove one unnecessary startup app.

Good to know

Do not disable school-managed background services.
