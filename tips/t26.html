Outlook · HOW TO

Create a Follow-up folder

A quick, practical reference you can use right away.

START HERE · FAST PATH
Mail sidebar → account → New Folder
⎙ Print

How to do it

Step 1

Control-click your account in the folder pane and choose New Folder

Step 2

Name it Follow-up and press Return

Step 3

Move a non-sensitive message into it via Move or drag and drop

EXAMPLE / WHEN THIS HELPS

Create one clear follow-up folder.

Good to know

Flags are often better for active reminders than storing everything in a folder.
