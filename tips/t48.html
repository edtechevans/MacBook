Chrome · HOW TO

Group tabs by project

A quick, practical reference you can use right away.

START HERE · FAST PATH
Tab context menu → Add tab to group → New group
⎙ Print

How to do it

Step 1

Control-click a tab, select Add tab to group, then New group

Step 2

Name the group, choose a colour and move related tabs into it

Step 3

Click the group name to collapse or expand it

EXAMPLE / WHEN THIS HELPS

Create a tab group for one teaching task.
