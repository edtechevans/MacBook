MacBook · HOW TO

Switch quickly between apps

A quick, practical reference you can use right away.

START HERE · FAST PATH
⌘ Tab
⎙ Print

How to do it

Step 1

Hold Command and press Tab to show the app switcher

Step 2

While still holding Command, press Tab to move through apps

Step 3

Release Command on the app you want

EXAMPLE / WHEN THIS HELPS

Move between Teams, Outlook and Chrome without using the Dock.
