Find the right calendar view

A quick, practical reference you can use right away.

START HERE · FAST PATH
Teams → Calendar → view dropdown
⎙ Print

How to do it

Step 1

Open Calendar in Teams

Step 2

Find the current view menu (often Work week)

Step 3

Select Day, Work week, Week or Month when offered

EXAMPLE / WHEN THIS HELPS

Compare Week and Work week views.

Good to know

Available views may change as Teams evolves.
