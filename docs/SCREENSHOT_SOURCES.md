# Authentic platform images

This learning site contains unaltered official screenshots as source-linked visual references **only within lesson walkthroughs**.

| Lesson | Platform | Image | Publisher |
|---|---|---|---|
| t22 (step 2) | macOS Tahoe | Screenshot toolbar | https://support.apple.com/en-in/102618 |
| t24 (steps 2–3) | Outlook for Mac | Schedule Send and date picker | https://support.microsoft.com/en-us/outlook/use-schedule-send-in-outlook-for-mac |
| t38 (step 2) | Microsoft Teams | Calendar view dropdown | https://support.microsoft.com/en-us/teams/meetings/get-started-with-the-microsoft-teams-calendar |
| t48 (step 1) | Google Chrome | Tab grouping context menu | https://blog.google/products-and-platforms/products/chrome/help-me-out-how-to-organize-chrome-tabs/ |

Sources and full-size images are linked in the lesson interface. Images are hosted by the publishers, **not stored in the GitHub repository**. We display complete original assets using CSS `object-fit:contain`, maintain aspect ratio, and never crop, recolour or annotate copyrighted screenshot files. We retain a text-based illustrated alternative for offline use, changes of UI layout, broken links or unsupported source images.

**Legal and editorial:** Microsoft's guidance allows specified educational/tutorial website use of screenshots subject to restrictions, including no partial reuse or alterations other than resizing and a statement "Used with permission from Microsoft": https://www.microsoft.com/en-us/legal/intellectualproperty/copyright/permissions . Google permits unaltered product screenshots in educational teaching materials: https://about.google/brand-resource-center/guidance/ . Apple's usage restrictions for Apple-owned images are separate: https://www.apple.com/legal/intellectual-property/guidelinesfor3rdparties.html . School communications/legal review is recommended before wider reuse; if permissions change, remove these references.

The Teams notification image was excluded because it visibly contained a profile name. Until a verified privacy-safe source is available, that lesson continues to use the illustrated guide.

The Chrome example was published in 2022 and may differ from today's Chrome. Apple toolbar reflects macOS Tahoe 26. Neither verifies the installed versions on AISG-managed faculty computers. The ideal next step is to replace publisher images with reviewed, privacy-safe school-authored captures where permitted, using test accounts with no student details.

For future updates, edit `lesson-media.js`, verify the source URL and exact step, confirm licence/privacy, and rerun browser accessibility and screenshot tests. Avoid using platform images in navigation or as branding.
