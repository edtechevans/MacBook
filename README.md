# MacBook Productivity - AISG Faculty Learning

A standalone, responsive learning website for MacBook, Outlook, Teams and Google Chrome.

Source: the reviewed 51-tip faculty PD guide (2 November 2026), with additional clearly labelled bonus tips.

## Features
- 51 guided walkthroughs plus bonus tips
- Searchable, filterable lesson library, per-tip deep links and direct links to official help
- Personal progress tracking and favourites stored locally in the visitor's browser (no accounts, analytics or student information)
- Goal-based pathways and interactive shortcut quiz
- Responsive layout, keyboard navigation and printable quick-reference sheet
- Accessible, dependency-free static HTML/CSS/JavaScript; no build process or data collection

## Develop
Open index.html with a local HTTP server, e.g. python3 -m http.server 8080, then visit http://localhost:8080.

## Deploy
A GitHub Pages workflow is included under .github/workflows/pages.yml. If GitHub Pages has not been enabled for this repository, set Settings > Pages > Build and deployment > Source: GitHub Actions, then run the workflow or push to main.

Expected project URL: https://edtechevans.github.io/MacBook/

## Editorial policy
UI menus depend on device software version, organisation account type and Microsoft 365 school configuration. Each lesson includes official support documentation where available. Demo tasks use non-sensitive example content; do not upload student or private school records.

Maintained as an editable, static resource for faculty learning.
